Problem 2
Solution:
We define the matrix $A$ so that the exponent matches the problem statement:
Let $A = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix}$, which implies $\theta A = \begin{bmatrix} 0 & -\theta \\ \theta & 0 \end{bmatrix}$.
Powers of $A$:
$$A^2 = \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix} \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix} = \begin{bmatrix} -1 & 0 \\ 0 & -1 \end{bmatrix} = -I$$
$$A^3 = A^2 A = -A$$
$$A^4 = (-I)(-I) = I$$
The cycle is: $A, -I, -A, I, \dots$
Taylor Expansion:
$$\exp(\theta A) = \sum_{n=0}^{\infty} \frac{(\theta A)^n}{n!} = I + \theta A + \frac{\theta^2}{2!} A^2 + \frac{\theta^3}{3!} A^3 + \dots$$
Grouping Terms:
Substitute the powers of $A$:
$$\exp(\theta A) = \left( 1 - \frac{\theta^2}{2!} + \frac{\theta^4}{4!} - \dots \right) I + \left( \theta - \frac{\theta^3}{3!} + \frac{\theta^5}{5!} - \dots \right) A$$
Recognizing the Maclaurin series for $\cos\theta$ and $\sin\theta$:
$$\exp(\theta A) = (\cos\theta) I + (\sin\theta) A$$
Substitute $A$ back into the expression:
$$\exp(\theta A) = \begin{bmatrix} \cos\theta & 0 \\ 0 & \cos\theta \end{bmatrix} + \sin\theta \begin{bmatrix} 0 & -1 \\ 1 & 0 \end{bmatrix} = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}$$
(Q.E.D.)
Problem 3
Solution:
We assume $\|u\|=1$. The skew-symmetric matrix $u^\wedge$ satisfies the following properties:
$(u^\wedge)^2 = uu^T - I$
$(u^\wedge)^3 = u^\wedge(uu^T - I) = -u^\wedge$ (since $u^\wedge u = 0$)
Derivation:

$$\exp(\theta u^\wedge) = I + \theta u^\wedge + \frac{\theta^2}{2!} (u^\wedge)^2 + \frac{\theta^3}{3!} (u^\wedge)^3 + \dots$$
Grouping odd and even powers:
Odd terms (coefficient of $u^\wedge$):
$$\left( \theta - \frac{\theta^3}{3!} + \dots \right) u^\wedge = \sin\theta u^\wedge$$
Even terms (coefficient of $(u^\wedge)^2$):
$$\left( \frac{\theta^2}{2!} - \frac{\theta^4}{4!} + \dots \right) (u^\wedge)^2 = (1 - \cos\theta) (u^\wedge)^2$$
Substituting back:

$$\exp(\theta u^\wedge) = I + \sin\theta u^\wedge + (1 - \cos\theta)(u^\wedge)^2$$
Using $(u^\wedge)^2 = uu^T - I$:

$$= I + \sin\theta u^\wedge + (1 - \cos\theta)(uu^T - I)$$

$$= I + \sin\theta u^\wedge + (1 - \cos\theta)uu^T - (1 - \cos\theta)I$$

$$= \cos\theta I + \sin\theta u^\wedge + (1 - \cos\theta)uu^T$$
(Q.E.D.)

$$B = \begin{bmatrix} 0 & 0 & 1 \\ 0 & 1 & 0 \\ -1 & 0 & 0 \end{bmatrix} \begin{bmatrix} 1 & 0 & 0 \\ 0 & c_{\alpha+\delta} & -s_{\alpha+\delta} \\ 0 & s_{\alpha+\delta} & c_{\alpha+\delta} \end{bmatrix} = \begin{bmatrix} 0 & \sin(\alpha+\delta) & \cos(\alpha+\delta) \\ 0 & \cos(\alpha+\delta) & -\sin(\alpha+\delta) \\ -1 & 0 & 0 \end{bmatrix}$$

$$R = \begin{bmatrix} \cos\delta & -\sin\delta & 0 \\ \sin\delta & \cos\delta & 0 \\ 0 & 0 & 1 \end{bmatrix} B$$
Using addition formulas (e.g., $\sin(\alpha+\delta)\cos\delta - \cos(\alpha+\delta)\sin\delta = \sin\alpha$):

Problem 6
Solution:
The geodesic distance is determined by the angle $\theta$ derived from the trace of the relative rotation $R_{\text{rel}} = R_1^T R_2$:

$$d_\theta(R_1, R_2) = \arccos \left( \frac{\text{Tr}(R_{\text{rel}}) - 1}{2} \right)$$
Let $R_1 = R_C R_A R_D$ and $R_2 = R_C R_B R_D$.
Compute the relative rotation:

$$R_{\text{rel}} = (R_C R_A R_D)^T (R_C R_B R_D) = R_D^T (R_A^T R_C^T R_C R_B) R_D$$
Since $R_C$ is orthogonal, $R_C^T R_C = I$:

$$R_{\text{rel}} = R_D^T (R_A^T R_B) R_D$$
Using the cyclic property of the Trace ($\text{Tr}(XYZ) = \text{Tr}(ZXY)$):

$$\text{Tr}(R_{\text{rel}}) = \text{Tr}(R_D (R_D^T R_A^T R_B)) = \text{Tr}(I \cdot R_A^T R_B) = \text{Tr}(R_A^T R_B)$$
Since the trace is invariant, the distance is invariant:

$$d_\theta(R_C R_A R_D, R_C R_B R_D) = d_\theta(R_A, R_B)$$
Problem 7
Solution:
We aim to find the minimum of the squared ratio (which minimizes the ratio itself, as $f(x)=x^2$ is monotonic for $x>0$):

$$\min_{x \neq 0} \frac{\|Ax\|^2}{\|x\|^2} = \min_{x \neq 0} \frac{x^T A^T A x}{x^T x}$$
SVD Substitution:
Let $A = U \Sigma V^T$. Then $A^T A = V \Sigma^2 V^T$.
Let $y = V^T x$. Since $V$ is orthogonal, $\|y\| = \|x\|$ and $y^T y = x^T x$.
The Rayleigh quotient becomes:
$$\frac{x^T A^T A x}{x^T x} = \frac{y^T \Sigma^2 y}{y^T y} = \frac{\sum_{i} \sigma_i^2 y_i^2}{\sum_{i} y_i^2}$$
Minimization:
To minimize this weighted average, the vector $y$ must align with the component corresponding to the smallest weight $\sigma_{\min}^2$ (the squared smallest singular value).
$$\frac{\sum \sigma_i^2 y_i^2}{\sum y_i^2} \ge \sigma_{\min}^2$$
Conclusion:

$$\min_{x \neq 0} \frac{\|Ax\|^2}{\|x\|^2} = \sigma_{\min}^2(A)$$
(Q.E.D.)
